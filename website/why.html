What people complain about, and what we did about it

We went through the complaints people post about every popular Linux system. Most are not about Linux itself. They are choices nobody made for you.

"There are too many versions and I don't know which to pick."
One of everything.One desktop, one app store, one way to update. You never have to choose between three tools that do the same job.
"An update broke my computer."
Updates can't break it.A new version is put down beside the one you are using. If anything is wrong after a restart, one click puts you back exactly where you were.
"It keeps forcing updates on me."
Nothing installs without you.Choose new features and security fixes, or security fixes only. Earlier versions stay available to go back to.
"I had to use the terminal to install a driver."
Drivers, codecs and game tools come built in.Nvidia, AMD and Intel graphics, video playback and Steam all work from the first start.
"I double-clicked a Windows program and nothing happened."
Windows programs get a real answer.Double-click a .exe and it runs, or you are told plainly why it can't and what to use instead.
"It looks nothing like what I'm used to."
It feels like home.Taskbar at the bottom, start menu in the corner, the keyboard shortcuts you already know, and close buttons where you expect them.

What we can't fix, said up front

  • Some online games block every system except Windows on purpose: Fortnite, Valorant, recent Call of Duty and Battlefield. We include cloud gaming shortcuts, and dual booting keeps Windows for those.
  • Adobe apps and the desktop versions of Microsoft Office are not made for Linux. LibreOffice opens and saves Word, Excel and PowerPoint files, and Office on the web works in the browser.
  • A few devices, such as some fingerprint readers, have no Linux drivers.
